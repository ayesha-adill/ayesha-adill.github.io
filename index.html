Biofill — Automated Syringe-Filling Device

Patent Pending · Inventor · Tessella Biosciences

+Add photo
+Add photo
CAD Model

What?

  • Designed an automated bioink syringe-filling device for a biotech client
  • Fills 2–10 mL syringes inside a biosafety cabinet with tight volumetric control

How?

  • Built 95% of components via 3D printing, designed in Autodesk Inventor
  • Programmed Arduino-based control logic in C++ to automate the fill cycle
  • Validated the housing with FEA and physical testing against motor force and piston loading
  • Investigated failure modes — piston detachment, locking-mechanism shear — and corrected the design

Results

  • Achieved ±0.05 mL fill accuracy with ≤1 mL dead volume per cycle
  • Now adopted into the client's active workflow
  • Findings compiled into an invention disclosure supporting a formal patent application
